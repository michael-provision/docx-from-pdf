Quickstart
==========

Convert a PDF from Python:

.. code-block:: python

   from docx_from_pdf import Converter

   converter = Converter("input.pdf")
   try:
       converter.convert("output.docx")
   finally:
       converter.close()

Convert a PDF from the command line:

.. code-block:: bash

   docx-from-pdf convert input.pdf output.docx

Convert a page range:

.. code-block:: bash

   docx-from-pdf convert input.pdf output.docx --start=0 --end=3

Extract tables:

.. code-block:: python

   from docx_from_pdf import Converter

   converter = Converter("input.pdf")
   try:
       tables = converter.extract_tables()
   finally:
       converter.close()
