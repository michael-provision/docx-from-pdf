docx-from-pdf
=============

``docx-from-pdf`` is a Python library and CLI for converting PDF files into
editable DOCX documents.

The package uses PDFium through ``pypdfium2`` for PDF parsing and rendering,
then writes DOCX output with ``python-docx``. It is published as
``docx-from-pdf`` and imported from Python as ``docx_from_pdf``.
