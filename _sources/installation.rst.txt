Installation
============

Install from PyPI:

.. code-block:: bash

   pip install docx-from-pdf

Upgrade from PyPI:

.. code-block:: bash

   pip install --upgrade docx-from-pdf

Install from source:

.. code-block:: bash

   pip install git+https://github.com/michael-provision/docx-from-pdf.git

Install local development dependencies:

.. code-block:: bash

   uv venv
   uv pip install -r requirements.txt

Uninstall:

.. code-block:: bash

   pip uninstall docx-from-pdf
